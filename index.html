01 / SERVICIOS

Del instrumento al informe, un solo flujo de datos

Seis líneas de trabajo que se combinan según el laboratorio. Cada pestaña muestra qué entregamos y cómo se ve.

Pipelines de datos de laboratorio

Llevamos los resultados desde donde nacen —reportes en Excel o PDF, correo, planillas de cadena de custodia, sistemas fuente— hasta una base normalizada. Cada carga queda versionada y pasa por reglas de validación explícitas.

  • ETL en Python con ingesta versionada de reportes
  • Validación de rangos, unidades, duplicados y códigos de muestra
  • Reproceso idempotente: cargar dos veces no duplica datos
  • Alertas cuando una carga falla o llega incompleta
  • Ejecución programada (GitHub Actions, cron, tareas del servidor)
Python · pandas · SQLAlchemy · PostgreSQL · SQL Server · Oracle

Administración y diseño de bases de datos

Modelamos la información del laboratorio para que la trazabilidad sea una propiedad del esquema y no un trabajo manual: de dónde vino la muestra, quién la analizó, con qué método y bajo qué versión del resultado.

  • Diseño relacional con modelo de custodia primero
  • Vistas e interfaces de lectura para LIMS y reportes
  • Índices, respaldos, roles y permisos por perfil
  • Migraciones versionadas y control de cambios del esquema
  • Historial de resultados: ninguna corrección borra el valor anterior
PostgreSQL · SQL Server · Oracle · SampleManager · vistas · particionado

Integración de instrumentos

Conectamos balanzas, equipos de espectrometría y otros instrumentos con el LIMS o el sistema corporativo, de modo que el dato pasa directo del instrumento al registro sin retipeo.

  • Balanzas analíticas por RS-232 o adaptador USB-TTL
  • Lectura de archivos de salida de ICP-OES, AAS y otros equipos
  • Escritura en grillas del LIMS y en SAP, incluso sobre Citrix
  • Verificación de estabilidad y reintentos ante lecturas ruidosas
  • Bitácora con fecha, hora, equipo y usuario por cada captura
Python · pyserial · Tkinter · ETRUCK · SAP · LIMS · PI SYSTEM

Desarrollo de reportes y portales

Informes que se generan solos y portales que se consultan desde cualquier dispositivo. El laboratorio deja de armar el informe mensual a mano y el cliente ve el estado del lote cuando lo necesita.

  • Informes PDF y Excel programados, con versión y firma
  • Portales de consulta con filtros por proyecto, lote y método
  • Cartas de control y tablas de QC embebidas en el informe
  • Exportación a CSV, Excel y PDF desde el mismo origen de datos
  • Plantillas con la identidad del laboratorio o del cliente
Streamlit · Plotly · openpyxl · ReportLab · HTML

Cumplimiento ISO/IEC 17025 y AMIRA P754

El sistema no reemplaza al sistema de gestión del laboratorio, pero produce la evidencia que los requisitos piden: trazabilidad, control de validez de resultados, incertidumbre y registros. Esta es la correspondencia con los requisitos que más se auditan.

Optimización de laboratorios con investigación operativa

Cuando hay más muestras que capacidad, el orden importa. Modelamos el laboratorio como un problema de programación de recursos y buscamos el plan que reduce tiempos de entrega y deja menos equipos ociosos.

  • Programación de preparación mecánica y ensayo químico (job shop flexible)
  • Asignación de equipos y analistas con restricciones reales
  • Dimensionamiento de capacidad y turnos con simulación
  • Heurísticas y búsqueda local cuando el modelo exacto es muy lento
  • Comparación cuantificada entre el plan actual y el optimizado
MILP · Pyomo · HiGHS · heurísticas · simulación de eventos discretos
02 / CONTROL ESTADÍSTICO

¿Está el proceso analítico bajo control?

Las cartas de control responden eso con datos. Cada ejemplo usa datos sintéticos: prueba a inyectar un desplazamiento y mira cuándo y cómo se detecta.

para qué sirve

Vigila a la vez el promedio y la dispersión de un proceso que se mide en grupos pequeños, por ejemplo las réplicas de cada lote.

cuándo usarla

Cuando se toman subgrupos de 2 a 5 mediciones bajo las mismas condiciones. Con un solo dato por corrida conviene la carta de individuales o Levey-Jennings.

cómo se lee

Se mira primero la carta R: si la variabilidad no es estable, la carta de promedios no se puede interpretar. Luego se buscan puntos fuera de límites y patrones.

qué hacer si hay señal

Detener la liberación del lote, buscar la causa asignable (calibración, reactivo, analista, equipo) y recalcular límites solo después de corregirla.

para qué sirve

Sigue en el tiempo el resultado de un material de referencia o muestra de control, y decide si una corrida analítica se acepta o se rechaza.

cuándo usarla

En cada corrida donde se incluye un material de control. Es la carta base del aseguramiento de la validez de resultados en 17025 (7.7).

cómo se lee

Las reglas de Westgard distinguen el error aleatorio (1₃s, R₄s) del sistemático (2₂s, 4₁s, 10x̄). Un punto entre 2s y 3s es solo advertencia.

qué hacer si hay señal

Error aleatorio: revisar pipeteo, contaminación, inestabilidad del equipo. Error sistemático: revisar calibración, estándares, reactivos y deriva del instrumento.

para qué sirve

Detecta desplazamientos pequeños y sostenidos, del orden de 0,5 a 1,5 desviaciones, que una carta Shewhart tarda mucho en mostrar.

cuándo usarla

Cuando la precisión es alta y el riesgo es la deriva lenta: desgaste de un tubo, envejecimiento de un estándar, cambios graduales de calibración.

cómo se lee

Cada punto pondera el dato nuevo con la historia. Si la línea suavizada cruza los límites, hay un corrimiento aunque cada dato individual parezca normal.

qué hacer si hay señal

Revisar tendencia en calibración, mantenimiento y lotes de reactivos. Se usa junto con Shewhart, no en lugar de ella.

LSL 40 USL 55 Desplazar media 0

para qué sirve

Responde si el método cumple la especificación con margen: compara el ancho de la especificación con la variabilidad real del proceso.

cuándo usarla

En validación de métodos y en aceptación de lotes con límites de especificación definidos. Requiere un proceso estable: primero la carta de control.

cómo se lee

Cp mide el potencial; Cpk descuenta el descentrado. Una diferencia grande entre ambos indica que la media se corrió. Con σ global se reportan Pp y Ppk, como aquí.

qué hacer si hay señal

Con Cpk bajo, primero centrar el proceso y luego reducir la variabilidad. Referencia habitual: Cpk ≥ 1,33 capaz; entre 1,00 y 1,33 marginal.

Límite RPD 10%

para qué sirve

Mide la precisión de la preparación y del análisis comparando una muestra con su propio duplicado.

cuándo usarla

En cada lote, con una frecuencia fijada en el plan de QC del laboratorio y distinguiendo duplicado de campo, de preparación y analítico.

cómo se lee

En la dispersión, los puntos deben seguir la diagonal. En las barras, cada par queda bajo el límite de aceptación definido para el analito.

qué hacer si hay señal

Revisar homogeneización, contaminación cruzada y pesaje. Si varios pares fallan en el mismo lote, reanalizar el lote completo.
